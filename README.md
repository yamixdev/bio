## Демонстрация

Сайт доступен по адресу:

**[yamixdev.github.io/bio](https://yamixdev.github.io/bio/)**

## Возможности

- информация об авторе;
- список проектов и программ;
- ссылки на социальные сети;
- адаптивный интерфейс;
- публикация через GitHub Pages;
- котики.

## Стек

- **HTML5** — структура страниц;
- **CSS3** — оформление и адаптивная вёрстка;
- **JavaScript** — интерактивные элементы.

Проект не использует фреймворки и может запускаться без установки зависимостей.

## Локальный запуск

### Простой способ

Скачайте репозиторий и откройте файл `index.html` в браузере.

### Через локальный сервер

```bash
python -m http.server 8000
```

После запуска откройте:

```text
http://localhost:8000
```

Также можно использовать расширение **Live Server** для Visual Studio Code.
