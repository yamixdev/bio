# IlushaDev — Bio

Персональный сайт-портфолио и центральный хаб для моих проектов.

Этот репозиторий содержит исходный код моей личной страницы. Проект создавался с вниманием к деталям, упором на производительность и плавность интерфейса. В основе лежит чистый код без использования громоздких фреймворков и сторонних библиотек.

## Основные возможности

- Синхронизация со Spotify в реальном времени с помощью Lanyard API для отображения текущего трека и прогресса прослушивания.
- Интеграция с несколькими сервисами для поиска котиков (Cataas, TheCatAPI, Shibe) с автоматической балансировкой серверов и переводом тегов.
- Собственная плавная система модальных окон, поддерживающая управление жестами (свайпами) на мобильных устройствах.
- Адаптивный и легкий интерфейс, спроектированный с акцентом на темную тему оформления.

## Технологии

Проект написан с использованием нативных веб-технологий:

- HTML5 для семантической структуры.
- CSS3 с использованием современных возможностей (переменные, Flexbox, Grid) для стилизации и анимаций.
- JavaScript (ES6+) для логики, асинхронной работы с API и управления DOM.

## Запуск проекта

Сайт не требует сложной настройки или предварительной сборки. Чтобы запустить его локально, достаточно скачать файлы репозитория и открыть `index.html` в любом современном браузере.

Для стабильной работы всех функций (в частности, для скачивания изображений в обход CORS-ограничений браузера) рекомендуется использовать простой локальный веб-сервер, например, расширение Live Server.

Исходный код (логика работы скриптов и структура HTML) открыт для изучения и свободного использования в ваших образовательных или технических целях.
